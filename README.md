## Projetos

###  MotusGlove

Protótipo de luva que acompanha a flexão de quatro dedos com sensores ópticos. O ESP32 disponibiliza as leituras via Wi-Fi em um painel web, onde é possível calibrar os sensores e controlar o display OLED.

Contribuí para o desenvolvimento do firmware e do painel web, a montagem elétrica, a integração dos sensores e do display, os testes e a documentação.
[Ver repositório](https://github.com/Luup2177/MotusGlove-esp32)

Aplicação web desenvolvida em equipe para organizar integrantes, atividades, conquistas e avisos de um grupo escoteiro.
